# NPAi Academy

Public course hub and CAD Prompt Creator. Thai interface with English CAD prompts.

- Video course opens on 12 October 2026 at 08:00, Asia/Bangkok (UTC+7).
- CAD Prompt Creator uses the learner's reference CAD style.
- NPAiRENDER: https://app.npairender.com

## Hosting

GitHub Pages serves `index.html` from the root of `main`. All visual assets are embedded. Hash navigation supports this project-site URL and offline HTML copies.

## Course links

The instructor's Google Drive link has not been supplied yet. The course settings dialog stores changes only in the current browser. To update the shared public course link, export the configured HTML, replace `index.html` with the exported file and commit it.

The release timer uses the device clock; it is not account authentication or a paywall. Configure access permissions on Google Drive separately.

## Browser storage

Prompt settings and local course settings remain in browser localStorage. File selectors record filenames only. Attach the actual source and reference CAD files when using the generated prompt with an AI assistant.
